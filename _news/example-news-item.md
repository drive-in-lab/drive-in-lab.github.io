**This is an example/template entry.** To add a news item:

1. Copy this file to `_news/YYYY-MM-DD-short-title.md` — the leading date
   in the filename sets the publication date and sorting order.
2. Edit the front matter: `title`, `date`, `category` (used for the filter
   dropdown on the News page), and `summary` (shown on cards).
3. Optionally set `image:` to a path under `assets/images/news/`.
4. Write the full story as Markdown below the front matter.

Delete this file once you no longer need the example.
