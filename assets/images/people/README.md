# People photos

Put each person's photo here (e.g. `tuomo-kujala.jpg`) and reference it
from their `_people/*.md` file's `photo:` field, for example:

```yaml
photo: /assets/images/people/tuomo-kujala.jpg
```

Recommended: roughly 4:3, at least 800×600px, JPG or WebP, under 300KB.
If a person has no `photo:` set, `placeholder.svg` is used automatically.
