**This is an example/template entry.** To add a real publication:

1. Copy this file to `_publications/short-title.md`.
2. Edit the front matter: `title`, `authors` (one per line), `year`,
   `type` (e.g. "Journal article", "Conference paper", "Thesis", "Report"),
   `venue`, and `tags` (used for search).
3. Put the PDF file in `assets/files/` and set `pdf:` to its path, e.g.
   `/assets/files/my-paper.pdf`. Set `doi:` (just the identifier, e.g.
   `10.1145/xxxxx`) and/or `link:` for an external copy.
4. Optionally paste a BibTeX entry into `bibtex:` to display a citation box.
5. Any Markdown written below the front matter appears as an abstract or
   notes on the publication's own page.

Delete this file once you no longer need the example.
